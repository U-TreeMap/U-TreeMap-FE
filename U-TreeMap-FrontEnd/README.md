# U-TreeMap Front-End

K-TreeMap(U-TreeMap)의 React 프론트엔드 앱입니다. 서비스 소개와 화면, 전체 구조는 [루트 README](../README.md)를 참고하세요.

## 실행

```bash
yarn install
yarn dev     # http://localhost:5173
yarn build
yarn lint
```

## 환경 변수 (`.env`)

```
VITE_MAPBOX_TOKEN=<your-mapbox-token>
VITE_API_BASE_URL=
```

더 자세한 설정은 [docs/setup.md](../docs/setup.md)를 확인하세요.
